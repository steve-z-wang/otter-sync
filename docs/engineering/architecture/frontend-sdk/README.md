# Frontend SDK

Generated types and language APIs submit application work to the Rust client and return typed outcomes. Bindings load the native carrier, route callbacks and execute requested HTTP/WebSocket/timer effects. Rust retains transactions, scheduling, retry, synchronization and settlement.

- [API](../sdks/typed-api/client.md)
- [Bindings](bindings.md)

Sources: [Node](../../../../packages/frontend/client-js), [Dart](../../../../packages/frontend/dart) and [React Native](../../../../packages/frontend/client-react-native). Public package names, exports and invocation syntax remain stable; internal API and Bindings modules have separate owners.
