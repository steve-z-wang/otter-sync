# @axtonjs/cli-darwin-arm64

> **Alpha.** AXTON is alpha software: its API is unstable and it is not ready for production use.

The `axton` compiler for macOS arm64. npm installs it as an optional dependency of [`@axtonjs/cli`](https://www.npmjs.com/package/@axtonjs/cli) on matching hosts; depend on `@axtonjs/cli` instead.
