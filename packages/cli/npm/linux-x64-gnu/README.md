# @axtonjs/cli-linux-x64-gnu

> **Alpha.** AXTON is alpha software: its API is unstable and it is not ready for production use.

The `axton` compiler for Linux x64 (glibc). npm installs it as an optional dependency of [`@axtonjs/cli`](https://www.npmjs.com/package/@axtonjs/cli) on matching hosts; depend on `@axtonjs/cli` instead.
