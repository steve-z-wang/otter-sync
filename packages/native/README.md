# @axtonjs/native

> **Alpha.** AXTON is alpha software: its API is unstable and it is not ready for production use.

AXTON's prebuilt Node addon. `@axtonjs/server` and `@axtonjs/client` load it; applications do not import it directly.

The addon for each supported target is its own package, `@axtonjs/native-<target>`, which npm installs as an optional dependency on matching hosts: `darwin-arm64` and `linux-x64-gnu`. The loader is generated by [napi-rs](https://napi.rs). On another host it throws `Cannot find native binding`, naming the unsupported OS or architecture among its causes; the same error, with the require failure as its cause, reports a platform package that was not installed (for example with `--omit=optional`) or cannot be loaded. The addon is never built from source.

See the [AXTON repository](https://github.com/zanminwang/axton).
