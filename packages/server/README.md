# @axtonjs/server

> **Alpha.** AXTON is alpha software: its API is unstable and it is not ready for production use.

AXTON's backend SDK for Node.js: `createBackend`, the sync routes and the native engine. Pair it with [`@axtonjs/postgres`](https://www.npmjs.com/package/@axtonjs/postgres) and the TypeScript that the [`axton` compiler](https://www.npmjs.com/package/@axtonjs/cli) generates from your schema.

See [backend setup](https://github.com/zanminwang/axton/blob/main/website/docs/backend/setup.md) for usage and reference.
